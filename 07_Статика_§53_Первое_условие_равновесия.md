# СТАТИКА

## Глава 7. Равновесие абсолютно твёрдых тел

## §53. Первое условие равновесия твёрдого тела

### Условие для внешних сил

Выясним, каким условиям должны удовлетворять внешние силы, приложенные к твёрдому телу, чтобы оно находилось в равновесии.

Сложим уравнения равновесия для всех элементов тела. Векторная сумма всех внутренних сил системы равна нулю, так как согласно третьему закону Ньютона любой внутренней силе соответствует сила, равная ей по модулю и противоположная по направлению. Поэтому в левой части остаётся только геометрическая сумма внешних сил, приложенных к телу:

\[
\vec{F}_1 + \vec{F}_2 + \ldots = 0 \qquad (7.2)
\]

> **Первое условие равновесия твёрдого тела: если твёрдое тело находится в равновесии, то геометрическая сумма внешних сил, приложенных к нему, равна нулю.**

Это условие является необходимым и достаточным для равновесия материальной точки. Для абсолютно твёрдого тела оно является необходимым, но **не достаточным**.

### Проекции сил

Если сумма внешних сил равна нулю, то равна нулю и сумма проекций этих сил на оси координат. В частности, для проекций внешних сил на ось \(OX\):

\[
F_{1x} + F_{2x} + F_{3x} + \ldots = 0 \qquad (7.3)
\]

Такие же уравнения можно записать для проекций сил на оси \(OY\) и \(OZ\).

### Пример

К одним элементам тела может быть приложено несколько внешних сил, а на другие элементы внешние силы могут и не действовать. Число всех внешних сил необязательно должно быть равно числу всех элементов.

Первое условие равновесия — это условие, которое вытекает из второго закона Ньютона для тела, не имеющего ускорения. Однако, как мы увидим в следующем параграфе, одного этого условия недостаточно.
