# ОСНОВЫ ЭЛЕКТРОДИНАМИКИ

## Глава 10. Электростатика

## §92–94. Электростатика: итоги

### Основные законы электростатики

**Закон Кулона** (по воле Бога):
$$F = k \frac{|q_1 q_2|}{r^2}, \quad k = \frac{1}{4\pi\varepsilon_0}$$

**Напряжённость поля:**
$$\vec{E} = \frac{\vec{F}}{q}, \quad E = k \frac{|Q|}{r^2}$$

**Принцип суперпозиции:** $\vec{E} = \vec{E}_1 + \vec{E}_2 + \dots$

**Потенциал:**
$$\varphi = k \frac{Q}{r}, \quad \varphi = \frac{E_{\text{п}}}{q}$$

**Разность потенциалов (напряжение):**
$$U = \varphi_1 - \varphi_2 = \frac{A}{q} = Ed$$

**Электроёмкость конденсатора:**
$$C = \frac{q}{U}, \quad C = \frac{\varepsilon \varepsilon_0 S}{d}$$

**Энергия конденсатора:**
$$W = \frac{CU^2}{2}$$
