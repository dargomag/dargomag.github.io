# СТАТИКА

## Глава 7. Равновесие абсолютно твёрдых тел

## §53. Первое условие равновесия твёрдого тела

### Равенство нулю суммы внешних сил

Первое условие равновесия твёрдого тела вытекает из второго закона Ньютона. Если тело покоится, ускорение каждого его элемента равно нулю. Следовательно, для каждого элемента сумма всех действующих на него сил (внешних и внутренних) равна нулю.

Складывая эти условия для всех элементов, получаем: **геометрическая сумма всех внешних сил, приложенных к телу, равна нулю**.

$$
\vec{F}_1 + \vec{F}_2 + \dots = 0
$$

В проекциях на оси координат:

$$
F_{1x} + F_{2x} + \dots = 0, \quad F_{1y} + F_{2y} + \dots = 0, \quad F_{1z} + F_{2z} + \dots = 0
$$

### Что это означает

Первое условие равновесия означает, что тело не движется поступательно. Если сумма внешних сил равна нулю, центр масс тела остаётся в покое или движется равномерно и прямолинейно.

Однако для твёрдого тела этого условия недостаточно. Тело может не двигаться поступательно, но вращаться. Поэтому нужно второе условие — условие отсутствия вращения.

### Примеры

Книга лежит на столе. Сила тяжести направлена вниз, сила реакции опоры — вверх. Их сумма равна нулю — первое условие выполнено, книга не движется поступательно.

Люстра висит на потолке. Сила тяжести уравновешена силой натяжения цепи. Первое условие выполнено.
