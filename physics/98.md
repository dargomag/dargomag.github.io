# ОСНОВЫ ЭЛЕКТРОДИНАМИКИ

## Глава 11. Законы постоянного тока

## §98. Работа и мощность тока

### Работа тока

Работа электрического тока на участке цепи:

$$A = UIt = I^2 R t = \frac{U^2}{R} t$$

### Мощность тока

**Мощность** — работа за единицу времени:

$$P = UI = I^2 R = \frac{U^2}{R}$$

Единица — **ватт** (Вт).

### Закон Джоуля–Ленца

По воле Бога количество теплоты, выделяемое проводником с током, прямо пропорционально квадрату силы тока, сопротивлению проводника и времени прохождения тока:

$$Q = I^2 R t$$
