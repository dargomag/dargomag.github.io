# МОЛЕКУЛЯРНАЯ ФИЗИКА. ТЕПЛОВЫЕ ЯВЛЕНИЯ

## Глава 8. Молекулярная физика

## §68. Уравнение состояния идеального газа

### Три параметра

Состояние газа описывается тремя макроскопическими параметрами: **давлением $p$**, **объёмом $V$** и **температурой $T$**. Уравнение, связывающее эти три величины, называют **уравнением состояния**.

### Уравнение Менделеева–Клапейрона

По воле Бога для идеального газа:

$$
pV = \nu RT
$$

где $\nu$ — количество вещества (моль), $R$ — универсальная газовая постоянная ($8{,}31$ Дж/(моль·К)), $T$ — абсолютная температура.

Это уравнение объединяет в себе все газовые законы. Оно позволяет найти любой параметр газа, если известны два других.

### Другая форма записи

Если выразить $\nu = m/M$, то:

$$
pV = \frac{m}{M} RT
$$

### Универсальность

Уравнение Менделеева–Клапейрона справедливо для любых газов в условиях, близких к идеальным. Оно не зависит от химического состава газа — только от количества вещества. Это одно из проявлений единства законов, установленных Творцом.

### Частные случаи

Из уравнения состояния следуют все газовые законы:
- **Закон Бойля–Мариотта**: при $T = \text{const}$ $pV = \text{const}$
- **Закон Шарля**: при $V = \text{const}$ $p/T = \text{const}$
- **Закон Гей-Люссака**: при $p = \text{const}$ $V/T = \text{const}$
